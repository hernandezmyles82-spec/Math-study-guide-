# Unit 3: Derivatives

## Key Definitions
- **Derivative**: the instantaneous rate of change of a function.
- **Tangent line** - a line that touches the curve at exactly one point locally.
- Critical point: a point where f'(x) = 0 or f'(x) is undefined.

## Rules
**Power Rule:**
$$\frac{d}{dx}[x^n] = nx^{n-1}$$

- Product Rule: $(fg)' = f'g + fg'$
- The derivative of a constant is **zero**.
- A function is continuous at a if the limit equals f(a).
- Slope of a horizontal line is 0.

Area of a circle = \pi r^2
A = lw

| Function | Derivative |
|---|---|
| sin x | cos x |
| e^x | e^x |

### Practice
Q: What is the derivative of x^3?
A: 3x^2

Q1. What is d/dx of 5? A: 0

Example 1: Find f'(x) if f(x) = 4x^2 + 3x.
Solution: Use the power rule on each term.
Final answer: f'(x) = 8x + 3

Mean value theorem :: If f is continuous on [a,b] and differentiable on (a,b), some c has f'(c) = (f(b)-f(a))/(b-a)
The {{chain rule}} is used to differentiate composite functions.
A polygon with three sides is called a triangle.
Concavity refers to the direction a curve bends.
